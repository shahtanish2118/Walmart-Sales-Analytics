# Walmart-Sales-Analytics
Overview

This project is an interactive Walmart Sales Analysis Dashboard built entirely in Microsoft Excel. The objective of this project is to transform raw sales data into meaningful business insights through data cleaning, modeling, analysis, and visualization.

The dashboard provides a comprehensive overview of sales performance by displaying key business metrics such as total revenue, total orders, average order value, average delivery time, monthly sales trends, category-wise revenue, top-performing products, top cities by orders, and daily order distribution. Interactive slicers allow users to filter the dashboard by occasion and date for dynamic analysis.

Features

* Interactive KPI Cards
* Revenue Analysis by Occasion
* Monthly Revenue Trend Analysis
* Top 10 Cities by Orders
* Revenue by Product Category
* Top 5 Products by Revenue
* Orders Distribution by Day
* Dynamic filtering using Slicers

Dashboard Insights

The dashboard helps users:

* Monitor overall sales performance through KPIs.
* Analyze revenue trends across different months.
* Identify the highest revenue-generating occasions.
